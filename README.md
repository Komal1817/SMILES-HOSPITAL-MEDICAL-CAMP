# Smiles Medical Camp

Current working project with automatic A5 letterhead orientation.

## Print behavior

- Portrait uploaded letterhead -> A5 Portrait (148 x 210 mm)
- Landscape uploaded letterhead -> A5 Landscape (210 x 148 mm)
- Letterhead keeps its aspect ratio and is used as the print background.
- Current print date and time are added automatically.
- JPG/PNG and PDF first-page letterheads are supported by the existing PDF handling.

## Run

Open the folder in VS Code and use Live Server on `index.html`.
